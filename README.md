# 灵动岛 Pro / IslandPro

**V1.0.0 experimental prototype; not a complete clone.** iOS 16–17 Rootless tweak.

Implemented in source: SpringBoard injection, `SBSystemApertureContainerView` layout hook, opt-in static-image overlay, opacity/scale controls and Darwin notification preference reload.

**Not implemented:** file picker, GIF/MP4, glow, particle effects, dual animation, recording/music/notification lifecycle, conflict detector. No device validation yet. Do not enable alongside ios16dao.

Only independently written source is published. No original proprietary dylib or authorization bypass is included. This repository has its own GitHub Actions workflow and does not modify other repositories.
